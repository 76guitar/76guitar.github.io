# Сайт гитарной мастерской 76guitar (Ярославль)

Временная версия сайта для согласования с мастером.
Постоянный адрес планируется на российском хостинге — домен `76guitar.ru`.

## Что здесь

- `index.html` — вся страница (услуги, акция −20%, работы, отзывы, контакты)
- `css/styles.css` — оформление, `css/fonts.css` — локальные шрифты
- `js/main.js` — меню, анимации, форма заявки
- `assets/` — фото работ и фото мастера, шрифты

## Важно

`robots.txt` закрывает тестовую версию от поисковиков, чтобы временный адрес
не конкурировал с боевым сайтом. При переезде на `76guitar.ru` этот файл
не переносится (или меняется на `Allow: /`).
